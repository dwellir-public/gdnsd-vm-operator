# gdnsd-vm implementation plan

Goal: create and deploy the approved generic DNS charm without touching n.
Architecture: Juju actions wrap native gdnsd file validation and control commands.
Technology: Python, ops, pytest, Jubilant, uv, tox and charmcraft.

The before/target compliance matrix is in the approved
[design](../specs/2026-10-28-gdnsd-vm-design.md#before-and-target-compliance-matrix).
Its actual-outcome column remains unverified until the validation report is written.

- [x] Document configuration updates in README.md before implementation.
- [ ] Write failing workload tests for per-zone isolation, validation failure,
  checksum conflicts, configuration rollback and package adoption.
- [ ] Implement src/workload.py for those transactions and first installation.
- [ ] Write event tests and implement src/charm.py, consolidated charmcraft.yaml,
  pyproject.toml, uv.lock and tox.ini. Do not implement workload upgrades.
- [ ] Implement and test scripts/pull_gdnsd_config.py and push_gdnsd_config.py.
- [ ] Add the requested running workload version and local control/UDP/TCP health checks on every update-status, with running state as the message.
- [ ] Run lint and unit checks, review specification conformance, then review code.
- [ ] Pack the charm and retain its checksum and build evidence.
- [ ] Create the retained Frankfurt gdnsd-nl model and provision one test machine.
- [ ] Deploy on existing US machine 0, verify x and protected hashes, then Tokyo.
- [ ] Deploy and validate the fresh Frankfurt instance with only x test data.
- [ ] Run pytest/Jubilant checks against explicit retained test models. Check valid
  and rejected x updates, push/pull round trips and refresh without restart.
- [ ] Record source commit, artifact digest, live results, matrix actual outcomes,
  model identities and any remaining limits in docs/validation.md.

The target directory was empty, so the new feature branch itself is isolated.
No existing checkout or branch is being repurposed. All models remain available
for manual inspection. No publication to GitHub or Charmhub is included.
